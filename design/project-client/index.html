ExoSett project role

Project client

We start here with an idea.

The project client defines what the building is for, whom it should serve and what success means. The brief brings together intended use, context, priorities, resources, programme and project constraints.

Contribution

Set the purpose and priorities

The client establishes the need before specialists determine the solution. Choosing an appropriate location, understanding its communities and infrastructure, and deciding how the building may need to change over time are part of that responsibility.

The brief should leave room for the building designer and module designer to develop good accommodation while making the client’s essential outcomes explicit.

Location

Adaptable accommodation need not occupy marginal or temporary land. Location shapes access, opportunity, community and daily life.

Interfaces

Own the brief, support the team

The client appoints and enables a competent project team, resolves priorities and accepts informed decisions. Clear interfaces allow each specialist to contribute without losing sight of the people, place and whole-life purpose behind the project.
