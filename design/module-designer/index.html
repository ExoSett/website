ExoSett project role

Module designer

Balancing engineering constraints against accommodation function.

The module designer realises accommodation requirements within the module envelope and the structural, service, fire-safety, manufacturing, transport, installation and removal constraints that meet it.

Contribution

Design the cassette for use and change

A module must work as accommodation during occupation and as a manageable cassette when manufactured, transported, installed, removed or refurbished. The Accommodation design page develops this distinction and the standards expected of the resulting spaces.

Those spaces are a collaboration: the project client defines the need, the building designer coordinates the whole place, and the module designer resolves the module itself.

Design subject

Explore the module designer’s interests

Accommodation design

ExoSett defines a building system rather than a universal dwelling. Good accommodation must respond to its occupants, purpose and wider architectural setting.

Explore accommodation design

Interfaces

Resolve every module boundary

The module designer coordinates loads, tolerances, connections, services, fire and smoke control, environmental performance, access and handling with the relevant specialists. These interfaces must remain safe and intelligible through installation, occupation, maintenance and later change.
