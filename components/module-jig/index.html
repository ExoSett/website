Module jig

A two-sided physical interface gauge for modules and accommodation frames.

The module jig embodies the contractual interface between an accommodation module and its cell. It allows modules and frames to be designed, manufactured and checked independently against the same physical reference.

Module-facing use

Present the interface of a cell

One face of the jig acts as a representative cell, presenting the exact interface that a module will encounter when it is installed in an accommodation frame. Module designers and manufacturers can use it to check that a completed cassette fits and engages with the required interface.

The same jig can be used with an installation frame. A delivered cassette is placed on the jig and the installation frame lifts the jig beneath it. If the module does not fit the installation jig, it will not fit the building.

Frame-facing use

Present the interface of a module

The opposite face acts as a representative module, presenting the exact interface that an accommodation frame will encounter when a module is installed. Frame designers and manufacturers can use it to check the cell geometry and interface.

Construction crews may also use the jig to verify completed accommodation frames before modules arrive. The same specified gauge therefore tests both sides of the interface.

Controlled definition

One shared contractual reference

The Building designer owns the module jig definition, which forms part of the building specification. It records the agreed module-to-frame interface for the corresponding module definition and becomes a critical input to both the Module designer and Frame designer.

The exact module envelope and the cell dimensions are closely related but not identical. Cell dimensions must also account for the installation mechanism, tolerances, fire-safety barriers and other required interfaces.

A building may establish a default module definition for all frame pairs and override it for particular frame pairs. Each module definition requires its corresponding jig specification. Once dependent design and manufacturing are under way, changing that definition may have extensive consequences.
