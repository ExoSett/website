ExoSett component

Pod jig

A two-sided physical interface gauge for pods and accommodation frames.

The pod jig embodies the contractual interface between an accommodation pod and its bay. It allows pods and frames to be designed, manufactured and checked independently against the same physical reference.

Pod-facing use

Present the interface of a bay

One face of the jig acts as a representative bay, presenting the exact interface that a pod will encounter when it is installed in an accommodation frame. Pod designers and manufacturers can use it to check that a completed pod fits and engages with the required interface.

The same jig can be used with an installation frame. A delivered pod is placed on the jig and the installation frame lifts the jig beneath it. If the pod does not fit the installation jig, it will not fit the building.

Frame-facing use

Present the interface of a pod

The opposite face acts as a representative pod, presenting the exact interface that an accommodation frame will encounter when a pod is installed. Frame designers and manufacturers can use it to check the bay geometry and interface.

Construction crews may also use the jig to verify completed accommodation frames before pods arrive. The same specified gauge therefore tests both sides of the interface.

Controlled definition

One shared contractual reference

The Building designer owns the pod jig definition, which forms part of the building specification. It records the agreed pod-to-frame interface for the corresponding pod definition and becomes a critical input to both the Pod designer and Frame designer.

The exact pod envelope and the bay dimensions are closely related but not identical. Bay dimensions must also account for the installation mechanism, tolerances, fire-safety barriers and other required interfaces.

A building may establish a default pod definition for all frame pairs and override it for particular frame pairs. Each pod definition requires its corresponding jig specification. Once dependent design and manufacturing are under way, changing that definition may have extensive consequences.
